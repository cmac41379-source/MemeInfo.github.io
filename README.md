# Meme Encyclopedia

A lightweight website that documents popular internet memes. Each meme has its own page with an image, origin, and description.

## Structure
- `index.html` — Homepage
- `memes/` — Individual meme pages
- `images/` — Meme images

## How to Add a Meme
1. Create a new HTML file in `memes/`
2. Upload the meme image to `images/`
3. Add a link to the new page in `index.html`
