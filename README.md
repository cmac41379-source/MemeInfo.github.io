# Meme Encyclopedia 🎉

A retro‑styled, chaotic, and fun web project that documents iconic internet memes while giving users interactive features like accounts, coins, profiles, friend lists, and more. Built with HTML, CSS, JavaScript, and Firebase.

---

## 🚀 Features

### 🔐 User Accounts (Firebase Authentication)
- Email + password login
- Signup & logout system
- Welcome message for logged‑in users
- Profile page with user data

### 🪙 Coins System
- Coins displayed in real time
- Stored per user in Firestore
- Used for shop unlockables (coming soon)

### 🛡️ Privacy & Safety
- Dedicated **Privacy & Safety** page
- Clear rules and protection for users
- Strong moderation system with blacklist filtering

### 👥 Friends System
- Send and receive friend requests
- Accept or decline requests
- Friends list with live count
### 📚 Meme Pages
- Doge
- Rickroll
- Nyan Cat
- More memes coming soon

### 🧠 Meme Personality Quiz
- Fun quiz that gives users a meme identity
- Retro UI styling

### 🎨 Retro Aesthetic
- Comic Sans everywhere
- Rainbow gradients
- Scrolling banners
- Glow animations
- Early‑internet chaos

## 🛠️ Setup Instructions

1. Clone the repository  
2. Add your Firebase config to your JS file  
3. Enable Authentication (Email/Password)  
4. Create Firestore collections:  
   - `users`  
   - `friends`  
   - `requests`  
5. Upload your meme images  
6. Deploy or run locally
